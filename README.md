# Pro GST Invoice Maker v2

Upload `index.html`, `style.css`, and `app.js` to a GitHub repository and enable GitHub Pages.

Features:
- Seller details editor directly in the app
- GSTIN/PAN/address/state/state code/pincode/phone/email
- Bank details and UPI
- Automatic invoice numbering
- Buyer/customer details
- Customer catalogue
- Product catalogue with HSN/SAC, unit, rate and GST
- GST rates 0, 5, 12, 18, 28 and 40 percent
- Intra-state CGST + SGST and inter-state IGST logic
- Taxable amount, GST, round-off and total
- Amount in words
- Invoice history
- Open, duplicate and delete invoices
- Print / Save as PDF
- Browser local storage

Important: This is an invoice/billing application, not an IRP e-invoicing/IRN integration. Before statutory use, have your CA/tax professional verify the GST treatment, HSN/SAC, place-of-supply and applicable invoice requirements for your business.
